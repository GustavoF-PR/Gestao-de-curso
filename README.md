# CCA - Sistema de Gestão de curso
Sistema web desenvolvido para o gerenciamento de **Cursos**, **Estudantes** e **Matricula** com estrutura **MVC** utilizando PHP e MongoDB
## Funcionalidades
- Curso e Estudante: Cadastro, listagem, edição e exclusão
- Matricula: Vínculo entre estudantes e cursos com registro automático
## Tecnologias utilizadas
- Back-end: PHP
- Front-end: HTML e CSS
- Banco de Dados: MongoDB
- Ambiente local: XAMPP (Apache) e MongoDB Compass
## Como executar localmente?
- XAMPP (com PHP e extensão php__mongodb habilitada)
- MongoDB rodando localmente
- Composer
